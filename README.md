## 📌 Project Overview

SepsisCare AI is an AI-powered ICU decision support system designed to assist in early detection of sepsis mortality risk. It combines machine learning with an interactive hospital dashboard to simulate real-world clinical workflows.

---

## 🚀 Features

- 🔍 Sepsis mortality risk prediction using XGBoost  
- 🏥 ICU patient management dashboard  
- 📊 Real-time analytics and batch monitoring  
- 🧾 Patient case history module  
- 💊 Prescription management system  
- 🤖 AI-based clinical explanation module  

---

## 📊 Model Details
